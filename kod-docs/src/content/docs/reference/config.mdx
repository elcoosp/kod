The config file lives at `~/.config/kod/config.toml` (Linux) or `~/Library/Application Support/kod/config.toml` (macOS), is auto-generated on first run, and every key below is optional — out-of-range values are clamped into valid ranges at load time with a warning. A missing or corrupt file falls back to defaults rather than failing the session.

## `[llm]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `network_access` | bool | `false` | Opt-in network access; gates `web_fetch`. Per-tool `network` in `.kod/policy.toml` overrides. |

## `[[llm.endpoints]]`

An array of named model servers; the first is the default. Everything that affects the wire lives on the endpoint.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `name` | string | `"default"` | Routing key referenced by `[llm.routing]`; duplicate names warn. |
| `provider` | string | `"openai-compatible"` | `"Ollama"` and `"OpenAI"` are aliases of `openai-compatible`. `"anthropic"` is recognised but fails at the first prompt. |
| `base_url` | URL | `http://localhost:11434/v1` | Normalised automatically — server root or `.../v1` root both work. |
| `model` | string | `"codellama:13b"` | Must exist on the server; what `kod models` lists. |
| `api_key_env` | string (optional) | — | Name of the env var holding the API key. The key itself never appears in the file. |
| `temperature` | float (optional) | `0.7` | Clamped to 0.0–2.0 at load. |
| `max_tokens` | integer (optional) | `2048` | Generation cap; `0` falls back to the default. |
| `context_window` | integer | `8192` | Sizes the memory budget and the context meter; clamped to ≥ 2000. |
| `timeout_secs` | integer | `300` | Per-request timeout; floored at 1. |
| `pricing.input_per_mtok_usd` | float (optional) | — | USD per million input tokens, for the TUI cost display. |
| `pricing.output_per_mtok_usd` | float (optional) | — | USD per million output tokens. |

## `[llm.routing]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `by_task` | map: task type → endpoint name | — | `"Simple"`, `"Debugging"`, … route to the named endpoint. Unknown names are dropped with a warning. |
| `fallback` | list of endpoint names | — | Ordered retry chain when the primary fails with a retryable error. |
| `swarm` | map: capability → endpoint name | — | `Planning`, `Coding`, … route swarm roles to different models. |

## `[memory]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `short_term_capacity` | integer | `100` | FIFO entries kept for the session. |
| `scope` | `"global"` \| `"project"` | `"global"` | `project` puts the long-term DB at `<cwd>/.kod/memory.redb`; `global` uses `~/.kod/data/kod.redb`. |
| `long_term_db_path` | string (optional) | — | Overrides both scopes with an explicit `redb` path. |
| `enable_semantic_search` | bool | `true` | Applies when an embedding endpoint is configured; retrieval is keyword + recency otherwise. |
| `embedding_endpoint` | `"none"` \| `"ollama"` \| `"openai"` | `"none"` | `ollama` derives the URL from `llm.base_url`; `openai` speaks `/v1/embeddings`. |
| `embedding_url` | string (optional) | — | Explicit embedder URL, overriding the derived one. |
| `embedding_api_key_env` | string (optional) | — | Env var holding the embedder API key (openai endpoint). |
| `embedding_model` | string | `"nomic-embed-text"` | Model name sent to the embedder. |
| `context_window` | integer | `4096` | Memory manager fallback budget. |
| `compaction_interval_secs` | integer | `3600` | Long-term store compaction cadence. |
| `extract_on_shutdown` | bool | `false` | One LLM call at session end pulls durable facts from the transcript. |
| `extract_max_entries` | integer | `12` | Cap on facts extracted per session. |

## `[skills]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `enable_hot_reload` | bool | `true` | Edits to skill files apply on the next prompt. |
| `max_skills_per_query` | integer | `3` | Skills matched per prompt, capped. |
| `skills_dir` | string (optional) | — | Replaces the four standard search directories with one custom path. |
| `match_threshold` | float | `0.3` | Minimum match score for a skill to ride along. Calibrated to the matcher's scale (tag 0.4, capability 0.3, trigger 0.8, name 0.9) — a higher threshold makes tag-only and capability-only matches unreachable. |

## `[swarm]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `max_agents` | integer | `5` | The decompose step targets this; the runner clamps to 2–8. |
| `merge_results` | bool | `true` | `false` (or a failed synthesis) concatenates per-agent results under their labels. |
| `agent_timeout_secs` | integer | `300` | Per-agent wall clock; a stuck agent is cancelled and retried. `0` disables. |
| `agent_retries` | integer | `1` | Extra attempts after a timeout or provider error. |

## `[tools]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `auto_check` | bool | `false` | After a successful write, run the project check (Cargo, tsc, ruff, go vet) and append diagnostics to the next prompt. |
| `auto_lsp` | bool | `true` | After a successful write, run language-server diagnostics on the touched files and append them to the next prompt. Cheap; no-op without a server on `PATH`. |

Write approval behaviour comes from the [policy presets](/guides/policy/), not from a config flag.

## `[lsp]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `auto_diagnostics` | bool | `true` | Run language-server diagnostics after a write and append them to the next prompt. Cheap; a no-op when no server is on `PATH`. |
| `settle_ms` | u64 | `500` | How long to wait for the server to settle before reading diagnostics. |
| `deferred_enabled` | bool | `true` | Queue diagnostics that arrive late and attach them to the next turn instead of dropping them. |
| `deferred_settle_ms` | u64 | `12000` | How long a deferred pass waits before giving up on a slow server. |

`[tools] auto_lsp` is the coarse switch; `[lsp]` tunes the behaviour once it is on.

## `[security.redact]`

Controls the prompt-path redactor. Log-write redaction is always on and not configurable.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `in_prompt` | bool | `false` | Run the redactor over every message and tool result before it reaches the model. Default off: a normal code-editing session needs un-redacted file contents. |
| `redact_argument_paths` | array of globs | `[]` | Blank the `arguments` of any tool call whose path matches, independent of `in_prompt`. Stronger than result redaction — the model never sees the arguments at all. |

Both settings replace a secret with `[REDACTED:<rule>]`, which the model cannot round-trip.

`kod` also installs a secret-placeholder vault at startup, by default: it loads (or creates) `~/.kod/secret-placeholder.key` and registers every secret-shaped environment variable, then the wire layer swaps a registered secret for a reversible placeholder the model can reason about. That is a separate mechanism from the redactor above and runs whether or not `in_prompt` is set. A failure to create the key file is logged and leaves placeholders disabled for the session — the pre-vault behaviour — rather than aborting startup.

## `[limits]`

Session and per-turn caps. `0` disables any individual limit.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `max_cost_usd_per_session` | f64 | `0` | Total spend ceiling for the session, in USD. |
| `max_cost_usd_per_turn` | f64 | `0` | Per-turn spend ceiling. |
| `max_input_tokens_per_turn` | integer | `0` | Cap on the prompt side of one turn. |
| `max_output_tokens_per_turn` | integer | `0` | Cap on the completion side of one turn. |
| `on_exhausted` | `ask` \| `stop` \| `continue` | `ask` | What to do when a cap is hit. `ask` pauses for a prompt (TUI only; a non-interactive caller treats it as `stop`), `stop` ends the turn keeping the partial reply, `continue` logs a warning and keeps going. |
| `soft_warn_at` | f64 | `0.5` | Warn when spend crosses this fraction of a cap. |
| `tools` | table | `{}` | Per-tool quotas, keyed by tool name; `"default"` applies to any tool not otherwise listed. |

A per-tool quota has `per_turn`, `per_session`, and — for `execute_command` — `per_command`, which limits how many times the same command string may run in one turn.

## `[jev]`

The [TypeSafe AI](https://typesafe.ai) integration. Opt-in; off by default.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Master switch. When false every call site falls back to the pre-Jev heuristic without a network call. |
| `api_key` | string | unset | Explicit key. Falls back to `TYPESAFE_API_KEY`. Never written in the clear — `kod config show-merged` and `kod config export` emit `[redacted]`. |
| `base_url` | string | unset | API root. Falls back to `TYPESAFE_BASE_URL`, then the public endpoint. Set this for a self-hosted gateway. |

## `[hooks]`

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `enabled` | bool | `false` | Master switch for both hook maps. |
| `pre_tool_use` | map: tool → command template | — | Runs before matching tool calls; `{path}`-style placeholders substituted from call arguments. |
| `post_tool_use` | map: tool → command template | — | Runs after matching tool calls. |

```toml
[hooks]
enabled = true
pre_tool_use  = { write_file = "rustfmt {path}" }
post_tool_use = { write_file = "cargo check" }
```

## `[mcp.servers.<name>]`

One block per MCP server; absent `[mcp]` means no plugins. A failing server is logged and skipped — one broken plugin never blocks the built-ins.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `command` | string | — | Program to spawn, resolved against `$PATH`. Empty commands are skipped. |
| `args` | string[] | `[]` | Arguments to the program. |
| `env` | map: string → string | — | Added to the child's environment (parent env is inherited). |
| `enabled` | bool | `true` | `false` keeps the block as a record without spawning. |
| `call_timeout_secs` | integer | `60` | Per-call timeout for `tools/call`. |

Tools are exposed to the model as `mcp:<server>.<tool>`.

## `[commands]`

User-defined TUI slash commands. Each key registers `/key`; `{args}` in the value is replaced by everything typed after the command name, `{cwd}` by the working directory.

```toml
[commands]
review  = "Review the last change in {cwd} and point out risks."
explain = "Explain what this code does:\n\n{args}"
```

## Project policy: `.kod/policy.toml`

Committed to the repository, layered over the global config (see [Policy & Permissions](/guides/policy/)):

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `preset` | `"read-only"` \| `"standard"` \| `"yolo"` | `"standard"` | Coarse baseline for the project. |
| `tools.<name>.mode` | `"allow"` \| `"deny"` \| `"ask"` | — | Overrides the preset for one tool. |
| `tools.<name>.paths` | string[] | — | Allow-list of path globs; unmatched paths are denied. |
| `tools.<name>.forbidden` | string[] | — | Deny globs; deny always wins over allow. |
| `tools.<name>.binaries` | string[] | — | Command allow-list (first token) for `execute_command`. |
| `tools.<name>.forbidden_binaries` | string[] | — | Command deny-list; wins over `binaries`. |
| `tools.<name>.network` | bool | — | Per-tool override of `llm.network_access`. |
| `tools.<name>.domains` | string[] | — | Domain allow-list for `web_fetch`. |
| `git.history_protected` | bool | `true` | Mounts `.git` read-only at the sandbox. |

## Environment variables

| Variable | Purpose |
| --- | --- |
| `KOD_SESSION_LOG` | Explicit session log path; default is `~/.kod/sessions/<unix-ms>.jsonl`. |
| `KOD_TUI_STATE_DIR` | Directory for the TUI session and prompt-history files. |
| `OPENAI_API_KEY` | Used by the `cloud-openai` profile (via the endpoint's `api_key_env`). |
| `KOD_TEST_MODEL`, `KOD_TEST_DB` | Live-model test opt-in for contributors; see [Testing](/developers/testing/). |

## Theme: `theme.toml`

A `theme.toml` next to the config selects the TUI palette:

```toml
theme = "light"        # or "dark", or a full [theme] table below
```

A bare `theme = "light"` line is accepted, as is a full `[theme]` table overriding individual ratatui colors (`black`, `red`, `green`, …). Loading is best-effort: an invalid theme file falls back to the default dark theme with a warning rather than failing the session. `kod theme show <name>` prints a built-in palette as JSON.

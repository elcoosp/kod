## Un seul binaire. Tous les modèles que vous exécutez déjà.

KOD est livré sous forme d'un seul exécutable Rust qui exécute la boucle de l'agent, les outils, le stockage en mémoire et l'interface utilisateur du terminal. Il n'y a pas de runtime Node, pas d'interpréteur Python et pas de démon Docker dans le chemin — juste `cargo build --release` et un serveur de modèle que vous contrôlez.

## Conçu pour ceux qui lisent leurs propres diffs

KOD est conçu autour d'une question : *où va mon code quand je lance ça ?* Chaque décision de conception — du modèle local par défaut au journal de session JSONL — existe pour que la réponse soit toujours « nulle part où vous n'avez pas choisi. »

<div class="kod-features not-content">

<div class="feat">
  <span class="icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M12 2 3 6v6c0 5 4 8.4 9 10 5-1.6 9-5 9-10V6l-9-4Z"/><path d="m9 12 2 2 4-5"/></svg></span>
  <h3>Politique avant chaque appel d'outil</h3>
  <p>Préréglages read-only, standard ou yolo, superposés à un <code>.kod/policy.toml</code> commité : allow/deny/ask par outil, globs de chemins et listes blanches de commandes. Le refus l'emporte toujours.</p>
</div>

<div class="feat">
  <span class="icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M2 12s3.5-7 10-7 10 7 10 7-3.5 7-10 7-10-7-10-7Z"/><circle cx="12" cy="12" r="3"/></svg></span>
  <h3>Auditable par conception</h3>
  <p>Chaque appel d'outil est enregistré en JSONL. <code>kod replay</code> ré-exécute les appels d'outils d'une session sans le modèle, vous pouvez donc vérifier n'importe quelle session par rapport au code à n'importe quel commit ultérieur.</p>
</div>

<div class="feat">
  <span class="icon"><svg viewBox="0 0 24 24" fill="none" stroke="currentColor" stroke-width="2" stroke-linecap="round" stroke-linejoin="round"><path d="M4 19.5A2.5 2.5 0 0 1 6.5 17H20"/><path d="M6.5 2H20v20H6.5A2.5 2.5 0 0 1 4 19.5v-15A2.5 2.5 0 0 1 6.5 2Z"/></svg></span>
  <h3>Compétences Markdown, rechargées à chaud</h3>
  <p>Déposez un fichier Markdown avec front matter YAML dans <code>~/.kod/skills</code> et le prochain prompt le verra. Déclencheurs, tags, capacités et exemples — sans rebuild, sans redémarrage.</p>
</div>

<div class="feat">

  <h3>Mémoire en couches sur disque</h3>
  <p>Contexte FIFO à court terme plus un stockage persistant <code>redb</code> à long terme — global ou limité au projet. Parcourez-le avec <code>kod memory</code>, exportez-le ou supprimez-le.</p>
</div>

  <h3>Essaims d'agents</h3>
  <p><code>kod swarm</code> décompose un objectif en sous-tâches, exécute jusqu'à 8 agents simultanément, détecte les conflits de fichiers et demande au modèle de fusionner les résultats.</p>

## Opérationnel en cinq commandes

<Tabs>
<TabItem label="Compiler depuis les sources">
  <Code lang="bash" code={`git clone https://github.com/elcoosp/kod.git
cd kod && cargo build --release

ollama serve &                 # or LM Studio, MLX, vLLM, …
ollama pull qwen2.5-coder:7b

./target/release/kod doctor
./target/release/kod profile use local-fast
./target/release/kod tui`} />
</TabItem>
<TabItem label="Essayer la CLI d'abord">
  <Code lang="bash" code={`# one-shot agent run against a goal
kod agent -g "add a doc comment to every public function in src/lib.rs"

# a single non-interactive prompt, ideal for scripts
kod prompt "explain what src/net.rs does in three bullets"

# a swarm of 4 agents on something bigger
kod swarm -g "implement and test a rate limiter" -n 4

# replay a recorded session as a regression check
kod replay ~/.kod/sessions/1730000000000.jsonl --execute`} />
</TabItem>
</Tabs>

<Aside type="tip">
  Vous n'êtes pas sûr que votre configuration fonctionne ? <code>kod doctor</code> imprime un rapport de diagnostic pour la config, l'endpoint, les compétences, la mémoire, le bac à sable et git en une seule fois.
</Aside>

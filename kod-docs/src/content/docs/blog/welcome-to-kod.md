Welcome to the official blog for **Kod**!

## What is Kod?

Documentation for KOD — the local-first AI coding agent harness for the terminal. Your code never leaves your machine.

## What to expect here

This blog is the central hub for everything related to Kod. We will be publishing:

- **Deep dives** into the architecture, design decisions, and inner workings of the project.
- **Tutorials and how-to guides** to help you get up and running quickly.
- **Release notes** and feature announcements as the project evolves.

Whether you are just discovering Kod or have been using it for a while, we are glad you are here. Stay tuned for our first official deep dive!

# kod-swarm

Coordinated multi-agent swarm collaboration for KOD.

Spawns child engines, routes sub-tasks to them, and merges their
results back into the parent turn — the primitive behind parallel
sub-agents. Each child runs with its own transcript, its own budget,
and a scoped tool set.

## Part of KOD

Reached transitively through `kod-core`.

See the [KOD workspace](https://github.com/elcoosp/kod).

# kod-skills

Markdown-based skill management for KOD.

Loads skill files from `~/.kod/skills` and from the project, composes
their content into the prompt, and tracks which are active for a
session. Skills are plain Markdown with frontmatter — no DSL.

## Part of KOD

Reached transitively through `kod-core`.

See the [KOD workspace](https://github.com/elcoosp/kod).

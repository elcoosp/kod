# kod-tools

Tool system for agent-environment interaction in KOD.

Implementations of the built-in tools: read, write, patch, execute,
list, grep, and the rest, each with its own argument schema,
permission scopes, and risk classification. The engine reaches these
through `kod-core-tools`.

## Part of KOD

Reached transitively through `kod-core-tools` and `kod-core`.

See the [KOD workspace](https://github.com/elcoosp/kod).

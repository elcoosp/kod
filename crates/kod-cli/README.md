# kod-cli

Command-line interface for the KOD terminal-native AI coding agent.

The `kod` binary: argument parsing, the interactive REPL, headless
`serve` mode, and the subcommands (`kod run`, `kod config`,
`kod policy`, etc.) that wrap the engine.

## Part of KOD

The end-user entry point.

See the [KOD workspace](https://github.com/elcoosp/kod).

# kod-core-state

Persistent state, journals, ledgers, and cost accounting for KOD.

Session journals that survive a crash, ledgers for tokens and cost,
the on-disk format for memory entries, and the state-machine
invariants that keep a session coherent across restarts.

## Part of KOD

Reached transitively through `kod-core`.

See the [KOD workspace](https://github.com/elcoosp/kod).

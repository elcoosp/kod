# kod-stats

Session statistics for KOD.

Per-session accounting: tokens, costs, elapsed time, tool call counts.
The engine updates it as it runs; the TUI displays it. Cheap to query,
designed to be included in a status bar on every render.

## Part of KOD

Reached transitively through `kod-core`.

See the [KOD workspace](https://github.com/elcoosp/kod).

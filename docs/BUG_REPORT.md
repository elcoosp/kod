## 8. Info — `WorktreeManager::create_session` is unreachable

**File:** `crates/kod-core/src/worktree.rs:281`

The new `create_session(clean_source: bool)` (plus `timestamp_token_utc` and three tests) has **no caller** anywhere in the workspace. It compiles and its tests presumably pass, but nothing wires it to a CLI command, swarm runner, or engine entry point, so the intended session-relocation feature does not exist from the user's side.

Secondary notes on the same function:

- The doc says the worktree is added from `HEAD`, but the code passes `self.base_commit`. These differ when `HEAD` has advanced past the manager's base. Pick one and make the doc match.
- The rollback path (`worktree remove --force` then `branch -D`) ignores both results with `let _ =`. If the branch delete fails, a dangling branch is left behind. At minimum, log at `warn`.

**Fix:** either wire `create_session` to the intended caller or mark it `#[allow(dead_code)]` with a tracking note; align the doc and `base_commit` wording; log rollback failures.

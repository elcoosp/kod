### B. Pedantic-wrong (~200) — DO NOT attempt without discussion

These fire on idiomatic Rust and are the exact reason tokio/serde/reqwest/axum put `#![allow(clippy::pedantic)]` at crate roots:

- **`similar_names` (30)**: `matches`/`matcher`, `content`/`context`, `prev`/`next`. Renaming degrades readability.
- **`wildcard_imports` (27)**: `use super::*` in tightly-coupled module hierarchies. The names resolve through `mod.rs` re-exports clippy cannot see.
- **`needless_pass_by_value` (23)**: 13 functions genuinely consume their value (moving into `json!` payloads, struct fields). Converting to `&T` requires `.clone()` inside, allocating per call.
- **`match_same_arms` (21)**: each arm has semantic reason to be separate (different variant names for reader clarity, per-arm comments explaining the match).
- **`items_after_statements` (15)**: `const`/`static` inside function bodies. Moving to module scope breaks scoping that makes them self-documenting.
- **`large_enum_variant` + `result_large_err` (3)**: `KodError` is intentionally large; boxing every variant changes every `Result` in the workspace.
- **`matching over ()` (5)**: all 5 are `select!` macro arms — the `_ =` syntax is required by the macro; clippy fires inside the expansion.
- **Long pedantic tail (~76)**: `must_use_candidate` on already-consumed `Self`, `needless_return` on boolean patterns where early-return is clearer, etc.

### C. Conversion-error leftovers (~164)

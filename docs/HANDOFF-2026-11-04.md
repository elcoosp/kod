## Concurrent-actor note

A `cargo watch`-style external process was observed committing staged
state after each batch script exited, using the batch's `/tmp/...msg`
file. Symptoms:

- `git commit` "another git process is running" (`.git/index.lock`).
- "nothing to commit" on retry (actor committed first).
- HEAD moving between Step 0 and Step 5 without the script reaching
  the commit line.
- **Untracked files left alone** when the commit loop gates on
  `git diff --quiet` (blind to `??`). This is why 6g's handoff write
  was left untracked and truncated.

**Workaround:**

```bash
START_HEAD=$(git rev-parse HEAD)
for i in $(seq 0 9); do
  if [ "$(git rev-parse HEAD)" != "$START_HEAD" ]; then COMMITTED=1; break; fi
  [ -f .git/index.lock ] && { sleep 1; continue; }
  git add -A 2>/dev/null || { sleep 1; continue; }
  [ -f .git/index.lock ] && { sleep 1; continue; }
  git commit -F "$MSG_FILE" 2>/dev/null || true
  if [ "$(git rev-parse HEAD)" != "$START_HEAD" ]; then COMMITTED=1; break; fi
  sleep 1
done
```

Do NOT gate on `git diff --quiet` — it misses untracked files.

## Methodology notes

1. **Diagnostic-first.** Dump source with line-context before editing.
   `--message-format=json` for authoritative spans.
2. **Brace-counted slices for signature changes.** When identical
   multi-arm bodies exist in sister functions, walk `{`/`}` from
   signature to close brace; apply edits only in that byte range.
3. **`re.subn` with `([ \t]*)` capture** for whitespace-agnostic
   multi-line replacements.
4. **File-based commit messages.** `git commit -F` avoids backtick
   substitution mangling.
5. **Per-file revert loop.** On `cargo check --message-format=json`
   error, extract failing file paths, `git checkout -- $file` for only
   those. This is how 34-fix batches stayed safe.
6. **Skip-on-shape-mismatch** for drifted anchors. Partially-apply and
   report; don't abort.
7. **HEAD-change commit detection** for the concurrent-actor problem.

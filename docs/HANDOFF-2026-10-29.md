## Process rules that earned their keep this session

1. **Grep the construct, not the shape.** Three misses this session:
   - `serve.rs:249` — multi-line `let _ = timeout(...)` escaped a single-line grep
   - "19 ToolContext literals" — 17 were function signatures (`fn x() -> ToolContext {`)
   - "conflict_handler structural gap" — the tool-layer wrapper was outside the grep scope

   Fix: `git show <file>:<line>`, read the surrounding function body, let the compiler or tests confirm.

2. **A passing test proves nothing until you disable the fix and watch it fail.** Two vault tests added this session; both reverse-tested before commit. The panic message names the leaking prompt, so a regression is diagnosable from the CI log alone.

3. **A flake that blocks three gates is a defect, not a flake.** `acp_handshake` failed 3 times at exactly 15.0s under parallel load, passed in isolation at 2.6s. Fix: 45s. Not "wait and retry."

4. **Never move a public tag.** `v0.1.24` stays at `936ee7fa` — CI-red in history — with the fix-forward chain answering it. Force-pushing a tag is the one operation with no recovery path.
